# proiect-de-pus-pe-rotom
Dispozitiv pentru gestionare ingrediente si retete.

Foloseste TheMealDB API pentru a obtine retete pe baza ingredientului selectat.
Stocheaza ingredientele valabile intr-o lista.
GUI afisat pe un ecran touchscreen rezistiv.

PCB-ul contine un cip ESP-WROOM-E32, stabilizator de 3.3V, convertor USB-UART.

Utilizare:
	Rotom.cpp si Rotom.h trebuie puse in folder-ul de librarii Arduino, intr-un folder "Rotom"
	User_Setup.h trebuie copiat/mutat in folder-ul librariei TFT-eSPI.
